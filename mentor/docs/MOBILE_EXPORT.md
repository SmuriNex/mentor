# Exportação Android

O projeto usa landscape sensor, renderizador Compatibility e interface baseada em anchors/containers. Para exportar, instale pelo editor o Android Build Template e configure JDK/Android SDK conforme a documentação da versão 4.6.

O Mentor não requer permissões de internet, microfone, câmera, localização ou armazenamento externo. Os dados são gravados no diretório privado `user://` do aplicativo.
